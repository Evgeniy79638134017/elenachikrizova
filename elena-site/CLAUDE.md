# Сайт врача-эндокринолога Елены Чекризовой

## О проекте
Персональный сайт врача-эндокринолога Елены Чекризовой (Южно-Сахалинск).
30 лет стажа. Специализации: эндокринология, гирудотерапия, нутрициология.
Цель — привлечение пациентов на приём и онлайн-консультации.

## Стек
Astro 5, Tailwind CSS 4, TypeScript, MDX, Vercel

## Дизайн
Цвета: зелёный (#2B6E5F основной, #3A8F7A светлый, #1E5448 тёмный),
тёплый акцент (#D4A574), фон (#FAFAF8), альт фон (#F0EFEB)
Шрифты: Playfair Display (заголовки), Raleway (текст)
Стиль: профессиональный, доверительный, тёплый

## Структура страниц
/ — Главная
/about — О враче
/services — Услуги (эндокринология, гирудотерапия, нутрициология)
/cases — Кейсы пациентов
/blog — Статьи
/contacts — Контакты и запись

## Команды
npm run dev — localhost:4321
npm run build — сборка

## НЕЛЬЗЯ
- НЕ создавать tailwind.config.js (Tailwind v4!)
- НЕ использовать @astrojs/tailwind
- НЕ писать «лечит», «гарантирует» → «помогает», «способствует»
